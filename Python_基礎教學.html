一、Python 簡介

Python 是一種直譯式、物件導向、動態語法的高階程式語言，由 Guido van Rossum 於 1991 年發布。

主要特色

  • 語法簡潔易讀，接近自然語言
  • 跨平台：Windows / macOS / Linux 都能跑
  • 豐富的第三方套件生態系
  • 應用領域廣：網頁、資料分析、AI、自動化、遊戲…

為什麼選 Python？

在 AI 與資料科學的時代，Python 已經是事實上的標準語言。學會它，幾乎什麼都能做。

二、環境安裝

步驟：

  • 到 https://www.python.org/downloads/ 下載安裝檔

  • 打開終端機輸入 python --version 驗證

四、變數與資料型別

變數命名

Python 不需要宣告型別，直接指派即可。

name = "Vans"
age = 30
height = 175.5
is_teacher = True

基本資料型別

# 字串 str
msg = "Hello Python"

# 整數 int
num = 42

# 浮點數 float
pi = 3.14159

# 布林 bool
is_active = True

# None
result = None

型別檢查

print(type(msg))    # <class 'str'>
print(type(num))    # <class 'int'>
print(type(pi))     # <class 'float'>

五、運算子

# 算術運算子
a, b = 10, 3
print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333...
print(a // b)  # 3  (整除)
print(a % b)   # 1  (餘數)
print(a ** b)  # 1000 (次方)

# 比較運算子
print(a > b)   # True
print(a == b)  # False

# 邏輯運算子
print(a > 5 and b < 5)  # True
print(not (a < b))       # True

六、流程控制

if 條件判斷

score = 85

if score >= 90:
    print("優等")
elif score >= 80:
    print("甲等")
elif score >= 70:
    print("乙等")
else:
    print("加油")

match-case (Python 3.10+)

command = "start"

match command:
    case "start":
        print("啟動")
    case "stop":
        print("停止")
    case _:
        print("未知指令")

七、迴圈

for 迴圈

# 跑 5 次
for i in range(5):
    print(i)  # 0 1 2 3 4

# 走訪清單
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

while 迴圈

count = 0
while count < 5:
    print(count)
    count += 1

break / continue

for i in range(10):
    if i == 3:
        continue   # 跳過這次
    if i == 7:
        break      # 提早結束
    print(i)

八、函式

把重複的邏輯包成函式，程式會更乾淨。

# 基本函式
def greet(name):
    return f"Hello, {name}!"

print(greet("Vans"))  # Hello, Vans!

# 預設參數
def power(base, exp=2):
    return base ** exp

print(power(3))     # 9
print(power(2, 10)) # 1024

# 多回傳值
def calc(a, b):
    return a + b, a - b, a * b

x, y, z = calc(10, 3)
print(x, y, z)  # 13 7 30

Lambda 匿名函式

square = lambda x: x * x
print(square(5))  # 25

九、串列 (List)

nums = [1, 2, 3, 4, 5]

# 常用操作
nums.append(6)        # 尾端新增
nums.insert(0, 0)     # 指定位置插入
nums.remove(3)        # 移除指定值
popped = nums.pop()   # 移除並回傳最後一個
print(len(nums))      # 長度
print(nums[0])        # 索引取值
print(nums[1:4])      # 切片

# 串列生成式
squares = [x**2 for x in range(5)]
print(squares)  # [0, 1, 4, 9, 16]

十一、檔案處理

# 寫入檔案
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("Hello Python\n")
    f.write("第二行\n")

# 讀取檔案
with open("note.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
💡 小提示：with 會自動關檔，比傳統的 open/close 安全。

十二、例外處理

try:
    num = int(input("請輸入數字: "))
    result = 100 / num
except ValueError:
    print("這不是數字！")
except ZeroDivisionError:
    print("不能除以 0")
else:
    print(f"結果是 {result}")
finally:
    print("執行結束")

十三、物件導向基礎

class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name}: 汪汪！"

my_dog = Dog("法鬥超人", "法鬥")
print(my_dog.bark())  # 法鬥超人: 汪汪！

繼承

class Bulldog(Dog):
    def __init__(self, name):
        super().__init__(name, "Bulldog")

    def bark(self):
        return f"{self.name}: 嗶嗶！(用鼻子發聲)"

十四、實戰小範例

範例 1：FizzBuzz

for i in range(1, 21):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)

範例 2：猜數字遊戲

import random

answer = random.randint(1, 100)
attempts = 0

while True:
    guess = int(input("猜 1~100: "))
    attempts += 1

    if guess < answer:
        print("大一點")
    elif guess > answer:
        print("小一點")
    else:
        print(f"答對了！共猜了 {attempts} 次")
        break

範例 3：計算字數

text = "Python is awesome. Python is easy."
words = text.split()
counter = {}

for w in words:
    counter[w] = counter.get(w, 0) + 1

print(counter)
